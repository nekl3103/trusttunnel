# Установка TrustTunnel на другой роутер или модем

## Что требуется

- Устройство должно работать под **OpenWrt 25.12 или новее**. На штатную
  прошивку оператора или производителя APK-пакет установить нельзя.
- Пакетный менеджер `apk`.
- Процессор `aarch64`, `armv7l`, `mips`, `mipsel` или `x86_64`.
- Не менее 25 МБ свободного места в `/overlay`. Для двух и более серверов
  желательно не менее 128 МБ оперативной памяти.
- Доступ к роутеру по SSH от пользователя `root`.
- `dnsmasq-full` с поддержкой `nftset` для маршрутизации по группам сайтов.

Перед установкой выполните на новом роутере:

```sh
cat /etc/openwrt_release
uname -m
free -m
df -h /overlay
command -v apk
```

Если OpenWrt старее 25.12, нет `apk` или архитектура отсутствует в списке,
устанавливать эту сборку нельзя.

## Установка зависимостей и клиента

Подключитесь к новому роутеру по SSH и запустите установщик:

```sh
sh -c "$(wget -O - https://raw.githubusercontent.com/nekl3103/trusttunnel/main/install.sh)"
```

Разрешите замену обычного `dnsmasq` на `dnsmasq-full`, когда установщик об
этом спросит. DNS домашней сети прервётся на несколько секунд.

После завершения проверьте:

```sh
test -c /dev/net/tun && echo TUN_OK
dnsmasq --version | grep nftset
/opt/trusttunnel_client/trusttunnel_client --version
```

## Установка текущей сборки с компьютера

Скопируйте два APK-файла на роутер. Вместо `192.168.1.1` укажите адрес нового
роутера:

```sh
scp -O luci-app-trusttunnel-1.1.0-r18.apk root@192.168.1.1:/tmp/
scp -O luci-i18n-trusttunnel-ru-*.apk root@192.168.1.1:/tmp/
```

Затем выполните на роутере:

```sh
apk add --allow-untrusted /tmp/luci-app-trusttunnel-1.1.0-r18.apk
apk add --allow-untrusted /tmp/luci-i18n-trusttunnel-ru-*.apk
rm -f /tmp/luci-indexcache
/etc/init.d/rpcd restart
```

Откройте LuCI: **Службы → TrustTunnel → Настройки**.

## Первичная настройка

1. Во вкладке **Серверы** добавьте сервер и вставьте ссылку `tt://` через
   кнопку **Импорт**. Для второго сервера повторите операцию.
2. Во вкладке **Группы сайтов** включите необходимые группы и выберите для
   них автоматический или закреплённый сервер.
3. Во вкладке **Устройства** добавьте телефон, телевизор или компьютер,
   выберите его IP/MAC и назначьте группы сайтов.
4. Во вкладке **Общее** включите **Маршрутизацию по устройствам**. После этого
   через туннель пойдут только назначенные пары «устройство — группа».
5. Включите **Запуск при загрузке**, нажмите **Сохранить и применить**.
6. На странице **Состояние** запустите службу и убедитесь, что серверы и
   группы отмечены как работающие.

Чтобы адрес устройства не менялся после перезагрузки, назначьте ему
постоянную DHCP-аренду в LuCI: **Сеть → DHCP и DNS → Статические аренды**.
При выборе MAC-адреса это не обязательно, но постоянный IP упрощает
диагностику.

## Перенос настроек со старого роутера

На старом роутере:

```sh
uci export trusttunnel > /tmp/trusttunnel-backup.uci
```

Скопируйте файл на компьютер, затем на новый роутер. На новом роутере:

```sh
uci import trusttunnel < /tmp/trusttunnel-backup.uci
uci commit trusttunnel
```

Пароли серверов намеренно не входят в UCI-экспорт. После переноса повторно
импортируйте ссылки `tt://` либо перенесите каталог `/etc/trusttunnel/secrets`
по защищённому соединению, сохранив права `700` для каталога и `600` для
файлов.

## Проверка

```sh
/etc/init.d/trusttunnel enable
/etc/init.d/trusttunnel restart
/etc/init.d/trusttunnel running && echo SERVICE_OK
ps w | grep -E 'trusttunnel_client|multi-watch' | grep -v grep
nft list table inet trusttunnel_multi
logread -e trusttunnel | tail -50
```

Если вкладка TrustTunnel не появилась, обновите страницу LuCI без кэша и ещё
раз выполните:

```sh
rm -f /tmp/luci-indexcache
/etc/init.d/rpcd restart
```
